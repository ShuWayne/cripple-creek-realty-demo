# Cripple Creek Realty — Premium Website Demo

A premium, interactive website concept for **Cripple Creek Realty LLC** (Truth or Consequences, New Mexico) — built by **Wayne.clips** studio to show what a modern rebuild of cripplecreekrealty.net could look like.

## What's inside

- Cinematic hero with the Elephant Butte Lake story
- Live property search & filters (type, price, bedrooms, keyword)
- 3D-tilt property cards with hover motion
- Lifestyle sections (lake, ranch, dark skies / Spaceport America)
- Broker story + tour-booking form
- Fully responsive, mobile-first
